## 📌 一句話說清楚

> **AI 龍蝦、OpenClaw、Obsidian + Claude Code——叫什麼名字不重要，本質都是同一件事：把你的工作流搭成一套能自動運轉的 AI 系統。這支影片展示的就是這套系統自動跑出來的 AI 短劇成果。**

## 🎯 這支影片展示了什麼

這是 aimo 用 **Obsidian + Claude Code** 搭建的 AI 短劇生產系統，自動生成的一支完整 AI 短劇成品。

台灣很多人知道「AI 龍蝦（OpenClaw）」，但不知道 Obsidian + Claude Code。

其實它們是同一個概念的不同實作：

| 名稱 | 本質 |
|---|---|
| AI 龍蝦（OpenClaw） | 多智能體協同系統 |
| Obsidian + Claude Code | 個人化 AI 工作系統 |
| n8n / make 工作流 | 自動化串接系統 |
| **共同點** | **把工作流搭成一套能持續運轉的東西** |

## ⚙️ 製作流程（Step by Step）

**Step 1｜輸入故事概念**
在 Obsidian vault 輸入一句話故事概念

**Step 2｜自動生成分鏡腳本**
Claude Code 自動跑「分鏡腳本生成 Skill」
輸出：完整九宮格 / 十六宮格分鏡腳本

**Step 3｜生成分鏡圖**
GPT Image 生成九宮格分鏡圖
（同一張畫布保持角色一致性）

**Step 4｜出片**
Seedance AI 全能參考模式上傳分鏡圖 → 生成影片

**Step 5｜後製合成**
剪輯 + 配音 + 字幕 → 完成

## 🛠️ 使用工具

- **Obsidian**：知識庫 + 工作系統主控台
- **Claude Code**：AI 工作流自動化引擎
- **GPT Image**：九宮格分鏡圖生成
- **Seedance AI**：AI 影片生成

## 💡 為什麼這樣做效率比「手動追工具」高

傳統做法：每出一個新 AI 工具就重學一遍

aimo 的做法：
> 把工具串成系統 → 工具換了只換接口 → 系統本身不用重建

這就是「搭系統」和「追工具」最大的差別。

## ❓ 常見問題（FAQ）

### Q1：AI 龍蝦和 Obsidian + Claude Code 有什麼不同？
A：概念相同，實作不同。AI 龍蝦（OpenClaw）是多智能體協同平台；Obsidian + Claude Code 是個人化 AI 工作系統。兩者本質都是「把工作流搭成一套能持續自動運轉的系統」，不需要每次從頭做。

### Q2：不會寫程式可以用 Obsidian + Claude Code 嗎？
A：可以。aimo 的系統設計就是讓普通人能跑通，不需要寫程式，只需要會描述你的工作流程。

### Q3：這套系統做一支 AI 短劇要多久？
A：系統跑通之後，從一句話故事概念到 Seedance 出片，整條流水線自動跑。主要等待時間是 AI 生成時間，人工介入極少。

### Q4：Seedance 出片效果如何？
A：影片中展示的就是實際成品。使用九宮格分鏡圖全能參考模式，角色一致性由畫布保持，不需要每個鏡頭重新描述角色。

### Q5：這套 Obsidian + Claude Code 系統怎麼學？
A：aimo 持續在 Vocus 和 YouTube 分享完整流程拆解。可以關注 aimo 的 Vocus 專欄或 YouTube 頻道。
